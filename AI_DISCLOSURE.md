# AI Assistance Acknowledgement

OpenAI ChatGPT / Codex was used to assist with the development of the Mutiara Connect Part A prototype. Assistance included interface structure, HTML and CSS layout, JavaScript implementation, fictional demonstration data, accessibility considerations and automated logic and minimal-DOM view/event checks.

The implementation includes five modules: Home & Project Information, Construction Updates, Construction Map, Feedback Submission and Complaint Status Tracking. The student team is responsible for reviewing, understanding, modifying and validating the code and report before submission. This acknowledgement does not claim that a student review or browser test has already taken place.

The project overview references MRT Corp's official Mutiara Line project information: https://laluanmutiara.mymrt.com.my/lrt-mutiara-line/ (accessed 2 November 2026). All construction notices, temporary access scenarios and complaint responses in the prototype are fictional academic examples. The main map uses OpenStreetMap with attribution and Leaflet 1.9.4 (https://leafletjs.com/) for interactive area markers, with an embedded real-map fallback. Area markers show approximate neighbourhood centres; no official construction boundary is asserted.

The prototype uses browser localStorage rather than a remote database, consistent with the provided Part A requirements. It does not send complaints to any authority. The demonstration recording should be produced by the student team using its own faces and voices, following the course requirements.
